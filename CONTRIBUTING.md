# Contributing to PeerLink

This repository is for internal research and transparency. Public contributions should follow the process outlined in [docs/incentives.md](docs/incentives.md).

## Banking Transcript Contributions

PeerLink compensates contributors for verified banking transcript artifacts. See [docs/incentives.md](docs/incentives.md) for reward details and how to get started.

**Do not post tokens, cookies, account IDs, HAR files, screenshots of bank records, or raw transcripts in any public forum.**

## Code Contributions

### Building
```bash
pnpm install
pnpm build
```

### Testing
```bash
pnpm test
```
