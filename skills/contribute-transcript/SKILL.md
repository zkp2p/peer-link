# Contribute Transcript Skill

This skill guides contributors through the process of adding transcripts to the Mercury evidence/coverage system.

## Overview

The transcript program is part of the Mercury initiative, which focuses on maintaining public schema and endpoint patterns for evidence/coverage discussions during the transcript-program migration.

## How to Contribute

### Before Contributing

1. **Wait for Approved Release**: Ensure an approved release is available before attempting to contribute.
2. **Campaign Reservation**: Explicitly reserve a slot in the campaign before making contributions.
3. **Check Availability**: Verify that public submission slots are open for the current campaign.

### Submission Process

1. Clone the repository
2. Navigate to the `transcripts/` directory
3. Add your transcript following the naming convention: `YYYY-MM-DD-topic-<contributor-id>.md`
4. Ensure your contribution follows the public schema guidelines
5. Submit a pull request with your transcript

## Important Guidelines

### What You Can Discuss
- Public schema patterns
- Endpoint designs
- Evidence/coverage methodology
- Technical implementation details

### What You Must NOT Share
- Banking credentials
- Account identifiers
- Raw records containing sensitive information
- Private financial data

## Reward Structure

- Current campaigns publish $5/$10 rates with 1–5 contributor capacity
- Historical issues do not create separate payable slots
- Prior earned or accepted commitments remain governed by their original terms

## Support

For questions about the contribution process, please open a discussion in the repository.
