# Retired: provider authoring

The old adapter/PR bounty workflow is retired. Do not claim an issue, request
assignment, scaffold a provider or open a bank PR to enroll for a reward.

Use [contribute-transcript](../contribute-transcript/SKILL.md) with the
[current release status](../../transcripts/release.json), bank campaign,
[privacy](../../docs/privacy.md) and [reward terms](../../docs/incentives.md).
The service is unreleased; do not collect/send credentials for an unavailable job.

The [previous provider runbook](https://github.com/zkp2p/peer-link/blob/31bba0e6c55f41ff08f31d30e728e1ef41d38a3b/skills/contribute-bank/SKILL.md)
is an immutable historical reference, not an active instruction. Existing reference
adapters may receive maintainer-scoped fixes, separately from paid transcripts.
Prior earned/accepted awards retain original terms, even if a legacy PR closes.
